# Portfolio quality checklist

This site is a static HTML/CSS portfolio. Review before merging or publishing changes:

- Check every external demo, LinkedIn, email, and project link manually.
- Run an HTML validator and an automated accessibility audit (e.g., axe or Lighthouse).
- Test keyboard-only navigation, visible focus, heading order, and 200% zoom.
- Check contrast of small text, especially muted text on dark backgrounds.
- Test narrow mobile widths and the `prefers-reduced-motion` preference.
- Confirm resume details and remove personal information not intended for public sharing.
- Add direct links to the Network Port Checker and Windows Security Audit projects.
- Use descriptive text for external links and avoid claiming unearned certifications.
- Keep the source simple; no third-party JavaScript or analytics is needed.

This checklist documents recommended manual verification, not completed test results.
